# Sistema de Cine - Programación IV

Trabajo Práctico #1 de la materia **Programación IV**.

El proyecto consiste en el desarrollo de una aplicación web integral para la gestión, comercialización y operación de un establecimiento de cine.

La aplicación permitirá contemplar tanto la experiencia de los clientes como las tareas administrativas y operativas del personal del establecimiento.

## Tecnologías

Actualmente el proyecto utiliza:

- Angular 22
- TypeScript
- HTML
- CSS
- Git y GitHub

Durante el desarrollo se incorporarán, de acuerdo con los requerimientos del trabajo:

- Supabase
- Supabase Auth
- Supabase Realtime
- Supabase Storage
- Row Level Security (RLS)
- PWA
- Web Push

## Requisitos del entorno

Para ejecutar el proyecto se requiere:

- Node.js 24
- npm 12
- Angular CLI 22
